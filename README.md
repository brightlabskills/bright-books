📚 _BRIGHT: Тёплая Книжная Лаборатория_

Добро пожаловать в интерактивный книжный навигатор от Лаборатории гибких навыков BRIGHT! Это удобное и душевное одностраничное приложение (SPA), созданное для того, чтобы помочь нашим клиентам ориентироваться в мире развивающей литературы.


👉 _ОТКРЫТЬ КНИЖНУЮ ПОЛКУ_


✨ Что умеет Книжная Лаборатория:
Тёплые советы от друга: Никаких скучных аннотаций — каждая книга снабжена личной, душевной рекомендацией.
Фильтрация по настроению (Vibes): Быстрый выбор книг под текущее состояние («Когда опускаются руки», «Для души», «Как навести порядок в делах» и др.).
Интерактивная полка («Моё избранное»): Возможность сохранять понравившиеся книги в один клик. Полка бережно сохраняется в памяти браузера (LocalStorage) и не пропадает при перезагрузке.
Генератор вдохновения: Случайные цитаты из книг для поиска мотивации в сложный момент.
Поиск в реальном времени: Мгновенный поиск по автору, названию или теме.
